 Sistema de Gerenciamento

Sistema desenvolvido em Python com Flask para gerenciar clientes, veículos e agendamentos de serviços.

Funcionalidades
- Cadastro, edição, listagem e exclusão de clientes.
- Cadastro, edição, listagem e exclusão de veículos.
- Gerenciamento de agendamentos de serviços.
- Login e autenticação de usuários.
- Integração com banco de dados MySQL.

Tecnologias utilizadas
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

Como executar
1. Instale as dependências do projeto.
2. Configure a conexão com o banco de dados MySQL.
3. Execute o arquivo principal do sistema.
4. Acesse `http://localhost:5000` no navegador.


Objetivo
Facilitar o gerenciamento de clientes, veículos e agendamentos de serviços em um único sistema.
